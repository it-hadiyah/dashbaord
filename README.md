# نظام تقارير المشاريع

موقع بدون قاعدة بيانات: الموظف يعبّي بيانات المشروع ويضغط إرسال، فيُنشأ تقرير كصفحة HTML تُحفظ في مجلد `reports/` على السيرفر.

## التشغيل على السيرفر (10.10.10.202)

```
node server.js          # يتطلب Node.js 18 أو أحدث، ولا يحتاج npm install
PORT=8080 node server.js
```

ثم افتح: `http://10.10.10.202:3000`

- التقارير المنشأة تُخدم من `/reports/<رقم-التقرير>.html`
- لإبقاء الخدمة شغالة: `pm2 start server.js --name reports` أو خدمة systemd.
