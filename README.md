# منشئ التقارير المؤسسية

منصة تقارير عربية (RTL) تعمل بدون قاعدة بيانات وبدون مكتبات خارجية: اختيار قالب → تعبئة الأقسام مع معاينة مباشرة على صفحات A4 → حفظ → طباعة/PDF أو تنزيل Word.

## التشغيل

```
node server.js                 # يتطلب Node.js 18 أو أحدث، ولا يحتاج npm install
PORT=8080 node server.js       # (PowerShell:  $env:PORT=8080; node server.js)
```
ثم افتح `http://localhost:3000`.

## الكليشة والهوية

عدّل `config.json` (اسم الجمعية، الاسم الفرعي، التذييل، بيانات التواصل) واستبدل `public/logo.svg` بالشعار. تنعكس التعديلات على كل التقارير (الجديدة والقديمة) لأن صفحة التقرير تُولَّد عند الطلب.

## الميزات

- **معرض قوالب** (14 قالباً بتكوين بصري مختلف: غلاف، عناوين، ألوان) مع معاينة مصغّرة حقيقية، بحث وتصنيف، وخيار «ببيانات تجريبية» (يظهر عليها شريط «بيانات تجريبية»).
- **محرر ثلاثي الأجزاء**: الأقسام والعناصر والتصميم (يمين) · محرر المحتوى (وسط) · معاينة A4 حية (يسار) مع تكبير وتصغير وتنقل بين الصفحات ووضع معاينة كامل، والضغط على أي قسم في المعاينة يفتح محرره.
- **الأقسام**: نص غني، قوائم، جداول (مع لصق من Excel)، بطاقات مؤشرات KPI، رسوم (أعمدة، خط، مساحة، دائري، أفقي)، مؤشرات تقدم، خط زمني، صور وشعارات، ملاحظات بارزة، فاصل صفحة. إضافة وحذف (مع تأكيد) وتكرار وإخفاء وترتيب بالسحب والإفلات أو الأزرار (Alt+↑/↓).
- **تراجع وإعادة** (Ctrl+Z / Ctrl+Y)، **حفظ تلقائي للمسودة** في المتصفح، وتنبيه عند وجود تغييرات غير محفوظة.
- **صفحات حقيقية**: تقسيم تلقائي للنصوص والقوائم والجداول الطويلة بين الصفحات (مع تكرار رأس الجدول)، ترويسة وتذييل، ترقيم صفحات، فهرس محتويات، غلاف وصفحة ختامية، هوامش قابلة للضبط، أرقام عربية أو لاتينية.
- **التصدير**: طباعة / PDF (متجه، A4، تحفظ الألوان والخطوط، واسم الملف من العنوان والتاريخ)، وملف **DOCX حقيقي** (عناوين وفقرات وقوائم وجداول قابلة للتحرير، والرسوم صور)، ونسخة JSON.
- **هوية هدية**: شعارات (ملونة وبيضاء، أفقية ورأسية)، زخرفة النخيل، وخط «The Year of Handicrafts» كخط أساسي (يعمل محلياً، وIBM Plex للحروف اللاتينية). مكتبة أيقونات (`public/brand/icons`): 29 أيقونة هوية رسمية، و67 أيقونة في تصنيف منفرد «أيقونات غير رسمية» بنفس الأسلوب (مشاريع ومبادرات، عناوين التقارير، إنجازات وأداء، مالية، تقنية، موارد وبرامج) وتُولَّد بالأداة `tools/gen-unofficial-icons.py`، تُستخدم بجانب عناوين الأقسام وفي بطاقات المؤشرات وكصورة وكرمز كبير على الغلاف.
- وضع فاتح وداكن (الورقة تبقى فاتحة للطباعة)، تركيز ظاهر وتباين مناسب للوحة المفاتيح.

## البنية

```
server.js                 الخادم (ملفات ثابتة + واجهة JSON + صفحة التقرير)
config.json               الكليشة
reports/<id>.json         كل تقرير = ملف JSON (المحتوى منفصل عن الشكل)
public/shared/templates.js   القوالب ونموذج البيانات (يُستخدم في المتصفح والخادم)
public/shared/render.js      مولّد التقرير + تنظيف HTML + الرسوم (مشترك)
public/js/paginate.js        تقسيم التقرير إلى صفحات A4
public/js/app.js, store.js, editors.js, gallery.js, preview.js, docx.js   المحرر
public/css/tokens.css        رموز التصميم (ألوان، مسافات، ظلال، وضع داكن)
public/css/app.css, report.css
```

نموذج البيانات: `{ version, template, palette, title, ..., options, sections:[{id, type, title, visible, width, content}] }`. تغيير القالب أو الألوان لا يغيّر المحتوى، والتقارير القديمة (النسخة الأولى) تُرقّى تلقائياً عند فتحها.

## الأمان

لا تسجيل دخول (النظام للشبكة الداخلية). نصوص المستخدمين تمر عبر قائمة بيضاء (بدون سمات ولا سكربتات) في المتصفح والخادم، والصور تقبل data URL لصيغ الصور فقط وبحد حجم، والمسارات الثابتة محمية من الخروج عن المجلد.
