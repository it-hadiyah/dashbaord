# نظام التقارير

موقع بدون قاعدة بيانات: أي موظف يعبّي بيانات تقريره ويضغط إرسال، فيُنشأ التقرير كصفحة HTML.

- القوالب: تقرير عام، تقرير مشروع، تقرير إنجازات ومهام، تقرير للمدير، اجتماع الإدارات، أو تقرير فارغ.
- الأقسام: نص، قائمة نقاط، جدول، أرقام ومؤشرات، ويمكن إضافتها وترتيبها وحذفها.
- `/list.html` يعرض كل التقارير مع بحث.
- كل تقرير يُحفظ في `reports/` كملفين: `<id>.html` (العرض) و`<id>.json` (البيانات).

## التشغيل (Node.js 18 أو أحدث، بدون npm install)

```
node server.js
PORT=8080 node server.js     # لتغيير المنفذ (في PowerShell: $env:PORT=8080; node server.js)
```
